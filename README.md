# Translation QA

Streamlit-приложение для поиска непереведённого английского текста на русскоязычных сайтах.

## Что внутри

- `app.py` — интерфейс, прогресс, статистика и выгрузка CSV/Excel.
- `crawler.py` — Playwright-краулер с прокруткой, раскрытием динамического контента, сбором ссылок, выборкой карточек товара и viewport-скриншотами.
- `sitemap.py` — чтение robots.txt, sitemap.xml и вложенных sitemapindex без новых зависимостей.
- `checker.py` — детектор английских слов и фраз с контекстом.
- `exceptions.py` — базовый белый список брендов, форматов и технических терминов.
- `selftest.py` — быстрый самотест детектора.
- `requirements.txt` — Python-зависимости.
- `packages.txt` — системные библиотеки Chromium для Streamlit Community Cloud.

## Запуск локально

```bash
pip install -r requirements.txt
python -m playwright install chromium
streamlit run app.py
```

## Публикация на Streamlit Community Cloud

1. Создайте публичный GitHub-репозиторий.
2. Загрузите в корень репозитория файлы `app.py`, `crawler.py`, `sitemap.py`, `checker.py`, `exceptions.py`, `requirements.txt` и `packages.txt`. Важно: `requirements.txt` должен лежать именно рядом с `app.py`, а не во вложенной папке.
3. Откройте [share.streamlit.io](https://share.streamlit.io/), войдите через GitHub и выберите репозиторий.
4. В поле **Main file path** укажите `app.py`, затем нажмите **Deploy**.

После сборки Streamlit выдаст публичную ссылку вида `https://название.streamlit.app`.

## Важные ограничения

- В интерфейсе доступны три режима: Sitemap (рекомендуется), навигационный обход и все ссылки.
- Sitemap сначала читает robots.txt, затем sitemap.xml/sitemapindex, отбрасывает служебные URL и сортирует страницы по priority и lastmod.
- В навигационном режиме проверяются главная, видимые ссылки из шапки/навигации/футера, разделы каталога и только несколько карточек товара в каждом разделе.
- Защитный предел обхода — 100 страниц; его можно снять отдельной галочкой в режимах навигации и всех ссылок.
- Ссылки на другой домен не обходятся.
- Название домена, логотипа и модели автоматически добавляются в белый список; эту функцию можно отключить для строгой проверки.
- Список собственных исключений сохраняется в текущей сессии приложения и может быть изменён перед каждым запуском.
- Для каждой страницы в отчёте показывается viewport-скриншот с кнопками копирования в буфер и скачивания файла.
- Playwright автоматически скачивает Chromium при первом запуске, если браузер ещё не установлен в окружении.
